# 👗 Clothing Accuracy Predictor

This website predicts how accurate a student’s outfit is for a specific occasion and weather condition.
It provides an AI-style analysis of clothing choices, scores them from 0–100%, and gives personalized feedback & suggestions for improvement.

## 🚀 Features

🎯 Occasion-aware predictions (business meeting, casual hangout, date night, gym, party, etc.)

🌤️ Weather-based adjustments (hot, cold, rainy, snowy, windy, etc.)

👕 Clothing & accessories input (tops, bottoms, shoes, colors, extras)

📊 Accuracy score with categories:

     🟢 Excellent Choice (85%+)

     🔵 Good Outfit (70%–84%)

     🟡 Fair Selection (50%–69%)

     🔴 Needs Improvement (<50%)

💡 Smart feedback & outfit suggestions

✨ Modern responsive UI with gradient design & smooth animations

## 📖 How It Works

1. Select your occasion, outfit items, footwear, and weather condition.

2. Add optional accessories and color combinations.

3. Click Predict Outfit Accuracy.

4. Get an accuracy score with analysis & suggestions.

### Example:

* Occasion: Business Meeting

* Top: Dress Shirt

* Bottom: Dress Pants

* Shoes: Loafers

* Weather: Cold

* Colors: Navy & White

### 👉 Output: Score 92% – Excellent Choice!
